# PKU Video Helper

**北大课程回放下载补丁：为能正常播放、却只能下载到 HTM 的课堂回放提供另一条下载路径。**

这是一个运行在 Tampermonkey（篡改猴）中的用户脚本，可与 [PKU Art](https://github.com/zhuozhiyongde/PKU-Art) 同时使用，也可以独立使用。它从当前回放播放器实际加载的媒体地址读取视频，校验内容后保存到本地。

[获取脚本](./PKU-Video-Helper.user.js) · [安装](#安装) · [使用](#使用) · [常见问题](#常见问题) · [更新记录](./CHANGELOG.md)

## 为什么做这个项目？

在部分教学网回放中，PKU Art 的下载按钮会得到一个很小的 `.htm` 文件，而非视频。打开后能看到类似提示：

> 您无权限访问当前课程中的课堂实录资源 .

与此同时，同一账号在网页播放器中仍然可以正常观看这节课。

这看起来像下载功能“被制裁”了，但目前确认的事实是：**原下载接口在实测场景中返回了权限错误页**。没有证据能够确定平台是否专门针对某个脚本，也不能据此认定所有课程、所有账号都无法使用 PKU Art 下载。

排查时查阅的 [PKU Art 下载实现](https://github.com/zhuozhiyongde/PKU-Art/blob/main/src/utils.js) 会从回放地址提取资源标识，再访问教学网的 `downloadVideo.action` 接口。本项目直接读取播放器使用的媒体清单和视频片段，避免依赖这条旧下载路径。

另外，服务器返回的 `Content-Type` 不一定准确。本项目会检查实际内容，而不是仅凭 `text/html` 就断定没有权限；真正的错误页仍会被拒绝保存。

感谢 PKU Art 提供的教学网使用体验和公开实现。本项目是独立的回放下载工具，不是 PKU Art 官方版本，也不需要替换其美化功能。

## 功能

- **识别当前回放**：从播放器回放信息、视频元素和已加载资源中发现实际媒体地址。
- **下载 HLS 分段回放**：读取 `.m3u8` 清单，按顺序下载、校验并合并片段。
- **保存原始音视频**：TS 分段保存为 `.ts`，支持的 fMP4 分段与直接 MP4 保存为 `.mp4`；不重新编码。
- **先验证，再保存**：解析清单后试读首段视频，避免把错误页面当成视频下载。
- **边下载边写入文件**：通过浏览器文件保存接口写入磁盘，不把整节课的视频全部堆在内存中。
- **显示进度与取消**：面板显示下载进度和已写入大小，支持中止当前下载。
- **自动建议文件名**：使用识别到的课程信息或页面标题作为文件名。
- **脱敏诊断**：提供失败阶段、HTTP 状态、响应类型等信息，便于定位问题。

## 适用环境

| 项目 | 要求或验证情况 |
| --- | --- |
| 浏览器 | 桌面 Chrome / Microsoft Edge，需支持 `showSaveFilePicker` |
| 脚本管理器 | Tampermonkey（篡改猴） |
| 目标页面 | `https://onlineroomse.pku.edu.cn/player` |
| 登录与网络 | 已登录教学网；当前网络能正常访问并播放回放 |
| 真实下载验证 | Windows + Edge + Tampermonkey，v1.0.3 已完成整节回放下载 |
| 其他环境 | Chrome 为目标兼容环境，尚未完成同等的整节下载实测；Firefox、Safari、手机浏览器不在当前验证范围 |

普通使用无需安装 Node.js、Python 或 FFmpeg。账号和正常播放权限由学校平台管理，本脚本不会为账号增加访问权限。

## 安装

### 1. 安装 Tampermonkey

从 [Tampermonkey 官方网站](https://www.tampermonkey.net/) 进入对应浏览器的扩展商店安装。

如果扩展提示不能运行用户脚本，请按照 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php#Q209) 检查浏览器中的“允许运行用户脚本”等设置，并确认扩展能在目标播放器网站运行。

### 2. 导入本脚本

1. 在本仓库点击 **Code → Download ZIP**，下载后解压。
2. 打开 Tampermonkey 的**管理面板 → 实用工具 → 从文件导入**。
3. 选择解压目录中的 **`PKU-Video-Helper.user.js`**，按提示安装。
4. 确认脚本处于启用状态，再刷新已经打开的回放页面。

也可以在 Tampermonkey 中选择“添加新脚本”，清空默认模板，粘贴 [`PKU-Video-Helper.user.js`](./PKU-Video-Helper.user.js) 的完整内容，再保存。

> 安装的是 `.user.js` 文件，不是整个 ZIP，也不是需要“加载已解压的扩展程序”的 Chrome 扩展目录。已安装 PKU Art 的用户可以继续保留它。

## 使用

1. 正常登录北大教学网，进入课程的**课堂实录 / 课程回放**。
2. 打开一节能够正常播放的回放，播放几秒。
3. 找到右下角新增的**“课程回放下载补丁”**面板。
4. 如果播放器嵌在教学网页面内，点击面板中的**“点击将播放器单独打开，再下载”**。
5. 点击**“解析回放”**，等待“清单与首段视频读取成功”。若没有发现媒体，先点“重新检测”。
6. 点击**“保存视频”**，选择文件名和保存位置。
7. 等待面板显示**“保存完成”**，再打开文件。

**请使用本补丁面板中的“保存视频”，不要与 PKU Art 原有的“下载视频”按钮混淆。** 下载进度显示在面板中，通常不出现在浏览器下载列表。

下载期间保持页面打开，避免刷新、关闭标签页或让电脑睡眠。可用磁盘空间应足以容纳整节回放；遇到同名文件时，可换一个文件名以保留原文件。

## 下载的 TS 文件能用吗？

可以。`.ts` 是 MPEG Transport Stream 视频容器，并不是错误页面。对于使用 TS 分段的回放，本脚本将原始片段合并成一个 TS 文件，保留其中的音轨和画面，不通过转码改变画质。

使用支持 TS 容器及其中音视频编码的播放器即可打开。如果需要 MP4，且电脑已经安装 FFmpeg，可在音视频编码兼容 MP4 时执行无损转封装：

```sh
ffmpeg -i "回放.ts" -c copy "回放.mp4"
```

这个操作不会重新编码；直接把 `.ts` 的文件后缀改成 `.mp4` 则不会改变容器格式。本脚本不自动安装 FFmpeg，也不自动转换文件。

## 常见问题

### 为什么 PKU Art 下载的是 HTM？

实测中的 HTM 是原下载接口返回的权限错误页面。文件本身没有视频内容，改成 `.mp4` 或 `.ts` 也无法播放。如果网页能正常播放，可以尝试本补丁的下载流程。

### 页面上没有出现补丁面板

确认 Tampermonkey 和脚本均已启用，浏览器允许用户脚本运行，然后刷新回放页。本脚本只在 `onlineroomse.pku.edu.cn/player` 播放器页面内运行，不会在课程首页或登录页显示。

### 提示文件保存功能不可用

将回放播放器单独打开成一个标签页，并使用支持文件保存接口的桌面 Chrome 或 Edge。此功能不能在教学网页面的嵌入式播放器里直接使用。

### 仍提示 HTML / JSON、401 或 403

新版会检查响应正文，不仅检查响应头。若确实收到错误页或拒绝访问，应先确认当前回放能正常播放，并尝试从课程列表重新打开回放。若仍失败，可复制脱敏诊断反馈；脚本不能代替学校平台恢复账号访问权限。

### 下载失败，留下了空文件

取消或失败时，脚本会中止尚未提交的文件写入。浏览器可能保留新建的空文件，这不代表下载完成。修复网络或访问问题后重新下载，当前版本没有跨页面断点续传。

### 是否支持所有课程和所有格式？

不保证。当前支持已结束的 HLS 回放、常见 TS / fMP4 分段、字节范围，以及清单提供的普通 AES-128 解密方式；直接 MP4 也有支持。

以下情况会停止并提示：直播尚未结束、独立音频分轨、时间线不连续、缺失片段、变化的初始化片段、不支持的加密方式（如 SAMPLE-AES / DRM）、服务器不按预期返回字节范围，或单次响应超过大小限制。直接 MP4 若不支持分段且一次返回超过 16 MiB，也会停止。

目前没有整门课程批量下载、自动重登录、后台常驻或自动转 MP4 功能。

### 如何反馈问题？

点击**“复制脱敏诊断”**，在仓库 Issue 中附上诊断、浏览器与 Tampermonkey 版本，以及原播放器是否能正常播放。

诊断不会主动包含课程名称、学号、密码、Cookie 或完整媒体链接。请不要另行上传账号密码、登录后的完整回放链接或浏览器网络日志中的凭据。

## 权限和工作范围

- 脚本只匹配上述回放播放器，不在作业、考试、成绩或选课页面运行。
- `unsafeWindow` 用于与真实播放器窗口交互，并正确调用浏览器保存接口。
- 下载请求使用页面内 `XMLHttpRequest`，由浏览器按当前会话处理凭据，不读取 Cookie 或要求填写学号、密码。
- 主动网络请求仅为 GET，限于媒体清单、片段、MP4 和清单指定的普通 AES-128 密钥。
- 允许的媒体主机为 `resourcese.pku.edu.cn`、`resource.pku.edu.cn`、`onlineroomse.pku.edu.cn`。
- 没有第三方运行依赖、统计服务或账号设置修改功能；不会代交作业。
- 只有点击保存时才请求选择本地文件，只有点击复制诊断时才写入剪贴板。

请仅保存自己有权访问的课程内容，并尊重授课教师和课程资料的使用要求。下载工具不附带课程视频，也不授予课程内容的传播许可。

## 验证情况

v1.0.3 已在 Windows / Edge / Tampermonkey 中完成一节约 **1 小时 58 分 59 秒**回放的完整下载，文件约 **1.22 GB**。文件结构检查识别到 H.264 视频与 AAC 音频，TS 包同步正常，音视频时间戳跨度与播放器时长一致；使用者已确认文件可用。

此外，23 项本地自动测试覆盖清单解析、错误页识别、错误 MIME 标注、AES-128、TS / fMP4 合并、MP4 分段读取、取消及脱敏信息。其他媒体格式的测试主要使用模拟响应，不等同于所有课程和浏览器都已实测。
